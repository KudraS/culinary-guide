## Описание проекта

Веб-приложение для хранения сведений о блюдах, способах и времени их приготовления, ингредиентах и их количестве.

База данных `culinary_guide` содержит четыре таблицы:

- `categories` — категории блюд;
- `dishes` — блюда и способы приготовления;
- `ingredients` — ингредиенты и единицы измерения;
- `recipes` — состав блюд и количество ингредиентов.

## Технологии

PHP, MariaDB, Composer. Локальная среда — XAMPP, среда разработки — PhpStorm.
